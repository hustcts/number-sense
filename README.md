## 📖 教育价值

### 数感能力培养

数感（Number Sense）是对数字、数量关系和运算的直观理解能力，包括：

1. **数量估计** - 不精确计算就能判断数量大小
2. **数字关系** - 理解数字之间的相对大小
3. **运算直觉** - 对运算结果的合理范围有预判
4. **模式识别** - 发现数字序列中的规律

### 适合人群

- **幼儿园 - 小学 2 年级**：简单难度，建立基础数感
- **小学 3-4 年级**：中等难度，提升计算速度
- **小学 5-6 年级**：困难难度，挑战逻辑思维

### 教学建议

1. **每日练习** - 建议每天玩 10-15 分钟
2. **循序渐进** - 从简单难度开始，逐步提升
3. **鼓励为主** - 关注进步，不过分强调分数
4. **讨论策略** - 引导孩子分享解题思路

## 🎮 游戏玩法

### 快速估计
- 屏幕上会显示若干个点
- 快速数一数，选择正确的数量
- 训练瞬间判断数量的能力

### 大小比较
- 显示两个数字
- 选择更大的那个
- 培养数字大小直觉

### 快速计算
- 显示加减法算式
- 心算得出答案
- 提升计算速度和准确性

### 数字规律
- 显示一组有规律的数列
- 找出下一个数字
- 锻炼逻辑推理能力

## 🏅 奖励机制

### 关卡奖励

| 准确率 | 星星 | 宝石 |
|--------|------|------|
| 90% 以上 | ⭐⭐⭐ | 15 |
| 70-89% | ⭐⭐ | 10 |
| 50-69% | ⭐ | 5 |
| 50% 以下 | - | - |

### 连对奖励

- 连续答对会获得额外分数
- 连对越多，分数加成越高
- 答错会重置连对计数

### 进度保存

- 游戏自动保存进度到本地
- 下次打开可以继续游戏
- 星星、宝石、徽章都会保留
